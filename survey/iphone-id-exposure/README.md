# 中古iPhoneの識別番号 公開状況調査（試験調査 50件）

メルカリ・Yahoo!オークション・楽天ラクマに出品されている iPhone 14 以降
（無印・Plus・Pro・Pro Max）の中古・ジャンク品について、出品者が
**IMEI・シリアル番号をどの程度公開しているか**を調べる。

## 記録の方針

- **番号そのものは記録しない。** IMEI・シリアルは「あり／一部伏せ字／なし／未確認」の区分だけを記録する。
  `aggregate.py` は、15桁の数字や英数字10〜12桁の文字列がどの列にあってもエラーにする。
- 画像が不鮮明で判断できない場合は推測せず「未確認」とする。
- 販売中と確認できない商品（売り切れ・取引中・終了・削除）は有効件数に含めない。
- 確認は各サイトの通常の閲覧画面で手作業で行う。スクレイピングや自動巡回、短時間の大量アクセスはしない。
- 出品者への問い合わせや、コメント欄で番号の開示を求めることはしない。

## 手順

1. `listings_template.csv` をコピーして `listings.csv` を作る（作業データはコミットしない）。
2. 各サイトで機種名を検索し、「販売中」で絞り込んで商品を開く。
3. 商品説明文と掲載画像をすべて確認し、下の記入ルールに従って1行記録する。
4. 3サイトの件数に大きな偏りが出ないように集める（目安は各サイト16〜17件）。
5. 有効件数が50件になるまで繰り返す。
6. 集計する。

   ```sh
   python3 aggregate.py listings.csv
   ```

   検証エラーが出た場合は、該当する行を直してから再実行する。
   出力は有効件数、除外件数（重複・販売中でないもの）、全体とサイト別の記載率、記載箇所の内訳。

## 記入ルール

| 列 | 記入する値 |
|---|---|
| 商品URL | 商品ページのURL（`?` 以降のパラメータは不要） |
| 取得元 | `メルカリ` / `Yahoo!オークション` / `楽天ラクマ` |
| 機種 | `iPhone 14` 〜 `iPhone 17 Pro Max`（例: `iPhone 15 Pro`） |
| 価格 | 円、数字のみ（オークションは確認時点の現在価格） |
| 状態 | `中古` / `ジャンク` |
| 販売状況 | 確認時点の表示。`販売中` 以外の行は集計から除外される |
| IMEI記載 | `あり`（全桁読める）/ `一部伏せ字` / `なし` / `未確認`（写っているが読めない、または判断できない） |
| シリアル記載 | IMEI記載と同じ区分 |
| 記載箇所 | `説明文` / `画像` / `説明文+画像` / `-`（両方とも記載なし） |
| 確認日時 | ISO形式（例 `2026-10-14T15:30+09:00`） |
| 備考 | 任意（例: 「設定＞情報のスクショ」「外箱ラベル」）。番号は書かない |

## 重複の扱い

- 同じ商品（URL中の商品IDが同じ）は1件として数える。2件目以降は集計時に自動で除外される。
- 同じ出品者が同じ端末を別サイトにも出している場合は、URLだけでは自動判定できない。
  写真や説明文から同じ端末だと判断できたら、2件目以降は記録しないか、`販売状況` を `重複` にして除外する。
